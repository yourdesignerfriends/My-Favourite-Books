## Why I Chose This Project
I decided to build this project around my favorite books because I love reading, and books have always been an important part of my life. Working with a topic that I enjoy makes the development process more motivating.

## My Favourite Books API
This project is a API I built using Node.js, Express, and MongoDB for Weeks 03 and 04 of CSE 341. It allows me to manage a personal collection of books through full CRUD operations, including creating, reading, updating, and deleting book entries stored in a MongoDB database. I structured the project using controllers, routes, middleware, and helpers to keep the code clean and maintainable, and I deployed the API to the web using Render.

## Features & Tools
I implemented data validation with custom middleware, secured the API using OAuth authentication, and documented all endpoints with Swagger to make the API easy to understand and consume. The project demonstrates my ability to build a complete backend application that follows professional development practices, integrates security, and includes clear API documentation.
